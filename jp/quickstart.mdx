---
title: "クイックスタート"
description: "成功への最短経路をたどるためのガイド"
---

ユーザーが製品を使い始める手順を説明します。最初に何をする必要がありますか？前提条件はありますか？

クイックスタートは、ユーザーをゼロから製品を使える状態まで導くものです。小さな成功体験を提供し、この製品で何ができるのかを実感してもらいましょう。

## 前提条件

始める前に、次のものが必要です。

- 要件その 1（例：Node.js 18 以降、無料アカウント、API キー）
- 要件その 2（例：対応デバイス、対応ブラウザ、対応 OS）

## はじめる

<Steps>
  <Step title="インストール">
    製品のインストール方法やサインアップ方法を説明します。

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="設定">
    初回利用前に必要なセットアップや設定を説明します。

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="実行">
    動作を確認するためにユーザーが最初に行う操作を示します。

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  ヘルプを得られる手段を用意しましょう。サポートページへのリンク、カスタマーサポートとのチャット、製品のフォーラムなどが考えられます。

  例：お困りですか？[support@yourcompany.com](mailto:support@yourcompany.com) までご連絡ください。
</Tip>
