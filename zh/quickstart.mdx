介绍别人如何开始使用你的产品。他们要做的第一件事是什么？是否有任何前置条件？

一份快速开始应当带用户从零开始使用你的产品。他们会获得一个小胜利，并了解自己能用它完成哪些事情。

## 前置条件

在开始之前，你必须具备：

- 条件一（例如 Node.js 18+、免费账号、API 密钥）
- 条件二（例如兼容的设备、兼容的浏览器、兼容的操作系统）

## 开始使用

<Steps>
  <Step title="安装">
    介绍如何安装你的产品或注册账号。

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="配置">
    介绍首次使用前所需的设置或配置。

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="运行">
    展示用户为了看到效果所需做的第一件事。

    ```bash
    your-cli start
    ```
  </Step>
</Steps>

<Tip>
  为用户提供获取帮助的途径。这可以是一个指向支持页面的链接、与客服代表的在线聊天，或者你产品的社区论坛。

  示例：需要帮助？请通过 [support@yourcompany.com](mailto:support@yourcompany.com) 联系我们。
</Tip>
